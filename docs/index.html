How it runs

Every run starts cold

A run builds its own workspace, its own tools, its own connection and its own conversation, then throws all of it away. Run the same agent twice and it does the work twice, with no idea it already ran.

What is kept: projects, field reports, what was sent, approvals, escalations. That's the record — it has to survive, or the system couldn't tell a client what it said yesterday.

What is discarded: the conversation, the loaded objects, anything held in memory.

Agents don't touch each other

Two agents running at once share the same data file, but never the same object in memory. Nothing the intake agent does can reach into what the client agent is holding.

Running from a phone

Off by default. A hosted address is reachable by anyone who has it, and running an agent spends money and can send real messages to real clients.

To turn it on, set LUMIA_RUN_TOKEN and ANTHROPIC_API_KEY in the host's variables. The page will then ask for that token once and remember it on this device.

From a terminal
