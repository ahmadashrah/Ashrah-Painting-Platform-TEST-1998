Lumia Control Room

Ashrah Painting Ltd. — 10 agents, 57 tools. Everything on this page runs the decision rules, not the model.

Live agent runs are blocked: ANTHROPIC_API_KEY is not set in the session, so the agents can't reason or act. The deterministic half — the send gate, content screening, verification, daily-log rendering, reports — works without it, and that's what you can drive here.

Send gate

Type a message the way an agent would draft it. The gate checks the recipient, then the message kind, then the words — same order, same rules as autonomy.py.

Agents

Each role holds a restricted toolset. L1 runs freely, L2 runs within approved rules, L3 is always queued for a human.

AgentDoesL1L2L3Needs a human

send_communication counts as L2 above, but it is the one tool resolved per call — its real level depends on the draft, which is what the panel above shows.

Screening rules

The Level 3 list, as patterns. Edit these and the gate above re-runs immediately. Scope all screens every message; external screens only messages leaving the company, so a tentative question to a crew lead isn't gated.


  


  
  

    
Where the code is

    
Three agent workstreams exist on three branches, and they have not been merged:

    

      

        
BranchAgentState

        
          
claude/ai-agents-github-setup-pqm1khLumia Marketingthe shared base both others build on

          
claude/lumia-communication-agent-hbpsajCommunication Agentpushed — this page describes it

          
claude/ashrah-scheduling-agent-j1cm72Scheduling Agentpushed, conflicts

        
      

    

    
The conflict is real, not cosmetic: both the communication and scheduling branches add a file called domain/projects.py, and both define Project and ProjectStatus with different fields and different status values (substantially_complete vs tentative/confirmed/deficiency). They also both edit autonomy.py, agents/__init__.py, cli.py, prompts.py, store.py and workspace.py. Merging means deciding whether a project is one record both agents share, or two.

  


  

    
Driving it from the terminal

    
export PYTHONPATH=src

python -m lumia.cli agents                  # this roster
python -m lumia.cli screen "That will be $4,200."
python -m lumia.cli gate send_communication --arg draft_id=comm_abc

python -m lumia.cli comms seed              # a demo project with a bad day on it
python -m lumia.cli comms intake            # needs an API key


    
Or from Python: from lumia import Lumia — then Lumia().agents(), .screen(...), .gate(...), .call(...) all work with no key. Only .ask() and the named cycles need one.
